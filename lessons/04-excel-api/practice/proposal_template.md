# Описание проекта

- **Участники пары.**

Тепин Максим Сергеевич, Антонов Данил Александрович

- **Аналитический вопрос.**

Какая часть решений и какая часть отказов приходится на десять организаций с наибольшим числом записей?

- **Зачем нужен ответ.**

Аналитикам, чтобы понять, насколько решения и отказы сосредоточены среди крупнейших кредитных организаций

- **Данные и отбор.**

Используем файл decisions.csv. Одна строка - одно решение по заявке. Используем поля lei, activity_year и action_taken. Отбираем десять организаций с наибольшим количеством записей

- **Показатель.**

Доля решений - количество решений десяти организаций / общее количество решений. Доля отказов - количество отказов десяти организаций / общее количество отказов. Оба показателя рассчитываются в процентах

- **Ограничение.**

Вывод относится только к данным округа Колумбия за 2023 год. На сравнение влияет разное количество заявок у организаций

- **Первый шаг.**

Один участник определит десять крупнейших организаций, второй рассчитает доли решений и отказов

- **После обсуждения.**

Возможное уточнение: отбирать организации по общему количеству решений, а не по количеству отказов, чтобы для обоих показателей использовалась одна группа организаций
